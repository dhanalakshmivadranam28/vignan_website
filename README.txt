VIGNAN UNIVERSITY — PREMIUM STUDENT WEBSITE
=============================================

Open index.html in a browser.

Pages:
Home, About, Academics, Departments, Admissions, Placements,
Research, Campus Life, Events & News, Contact.

Tech:
HTML5 + CSS3 + JavaScript only. No backend.

This version is intentionally more visual:
- Full-width image hero
- Image-based page headers
- Campus/laboratory/library/student imagery
- Editorial cards and visual grids
- Responsive layouts
- Mobile navigation
- Animated counters
- Department search/filter
- Admissions tabs
- Front-end-only forms
- Scroll reveal effects

The image URLs are remote web images, so an internet connection is needed to display them when opening the local HTML files.
Institutional facts and figures marked with * should be verified against current official university information before submission/publication.
